.. _WdTabLeader:

``WD_TAB_LEADER``
=================

.. tab:: 中文

    指定用作带格式化制表符的前导符的字符。

    ----

    SPACES
        空格。默认。

    DOTS
        点。

    DASHES
        虚线。

    LINES
        双线。

    HEAVY
        粗线。

    MIDDLE_DOT
        垂直居中的点。

.. tab:: 英文

    Specifies the character to use as the leader with formatted tabs.

    ----

    SPACES
        Spaces. Default.

    DOTS
        Dots.

    DASHES
        Dashes.

    LINES
        Double lines.

    HEAVY
        A heavy line.

    MIDDLE_DOT
        A vertically-centered dot.
